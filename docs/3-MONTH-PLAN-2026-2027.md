## 2. Technical Content Model (`src/lib/blog.ts`)

ReKit blog guides are typed in TypeScript and statically generated into `/blog/[slug]` and `/sitemap.xml`.

```typescript
export type BlogPost = {
  slug: string;                           // Lowercase kebab-case matching target query
  title: string;                          // SEO title (compelling, clear)
  description: string;                    // Meta description (120-160 chars)
  date: string;                           // ISO date format YYYY-MM-DD
  minutes: number;                        // Estimated reading time (typically 4-6 min)
  category: "Image" | "PDF" | "Text" | "Utility" | "Security";
  toolSlug?: string;                      // Slug of matching live tool in src/lib/tools.ts
  author: string;                         // Default: "ReKit Team"
  content: {
    problem: string;                      // Why server uploads risk privacy and cause friction
    steps: { title: string; body: string }[]; // Step-by-step instructions
    tips?: string[];                      // 2-3 pro tips for best results
    faq: { q: string; a: string }[];      // 2-3 structured FAQ entries
  };
};
```

## 3. Blog Post Code Template

Insert this block into `src/lib/blog.ts` within the `BLOG_POSTS` array:

```typescript
  {
    slug: "target-slug-from-table",
    title: "How to Target Action With Tool Name",
    description:
      "A compelling 1-2 sentence meta description explaining the local in-browser conversion and privacy benefit.",
    date: "YYYY-MM-DD",
    minutes: 5,
    category: "Image", // or "PDF" | "Text" | "Utility" | "Security"
    toolSlug: "matching-live-tool-slug",
    author: "ReKit Team",
    content: {
      problem:
        "Explain why this task is frustrating or hazardous on server-upload websites (cloud storage risks, queues, paywalls).",
```
