FAQ

Frequently Asked Questions

Is iUseTools really free?

Yes, completely free. All 30+ tools are available without any payment, subscription, or account creation.

Are my files safe when I use iUseTools?

Your files never leave your device. All processing is done entirely in your browser. We have no servers that receive your files.

Do I need to create an account?

No. iUseTools requires no registration, no email, and no personal information.

What file types are supported?

We support PDF, JPG, JPEG, PNG, WebP, BMP, TXT, CSV, JSON, and Markdown files as inputs, with outputs in DOCX, PDF, TXT, PNG, JPG, and JSON formats.

Is there a file size limit?

PDF files up to 50MB and image files up to 20MB are supported.
