# Keyword & Content Log — ReKit (`reversed/`)

Rule: **No new blog guide, conversion tutorial, or SEO landing is published without an approved row below.**  
Every guide must target a verified organic search query, explain why client-side conversion protects user privacy, and deep-link directly to an interactive tool.

### Required Fields per Candidate:
1. **Target Date:** Scheduled publication date.
2. **Target Query:** High-intent search query.
3. **Intent:** What the user wants to convert, manipulate, or compute.
4. **Competing Pages:** Current ranking converter sites on Google SERP.
5. **Distinct ReKit Angle:** 100% in-browser processing, zero server uploads, privacy-first, no paywalls.
6. **Live Tool:** Connected live tool slug on `rekit.tools`.
7. **Target Slug:** Kebab-case URL slug.
8. **Status:** `[x] Shipped` or `[ ] Scheduled`.
